# Running Standalone .pyg Files

## Overview

The `.pyg` files generated by `pg-convert` can be made standalone-executable with the `--standalone` flag. This adds:
- Automatic `from MathObjects import *` (for Context, Compute, etc.)
- Imports placed BEFORE `DOCUMENT()` (so they're available immediately)
- Boilerplate `if __name__ == "__main__"` block to display results

## Usage

### Generate Standalone .pyg File

```powershell
python -m pg_translator.cli tutorial/sample-problems/Algebra/Logarithms.pg --standalone
```

This creates `Logarithms.pyg` with:
```python
from MathObjects import *
from PGML import *
from PGcourse import *
from PGstandard import *

DOCUMENT()
# ... problem code ...
ENDDOCUMENT()

if __name__ == "__main__":
    # Boilerplate to display results
    from pg_macros.core.pg_core import get_environment
    env = get_environment()
    if env:
        print("=" * 80)
        print("PROBLEM STATEMENT")
        # ... prints statement, solution, answers
```

### Run Standalone .pyg File

**Option 1: Using the wrapper script (easiest)**
```powershell
.\run-pyg.bat tutorial\sample-problems\Algebra\Logarithms.pyg
```

**Option 2: Manually setting PYTHONPATH**
```powershell
$env:PYTHONPATH="d:\pg\packages;d:\pg\packages\pg_math;d:\pg\packages\pg_pgml;d:\pg\packages\pg_parser;d:\pg\packages\pg_answer;d:\pg\packages\pg_renderer;d:\pg\packages\pg_macros"
python tutorial\sample-problems\Algebra\Logarithms.pyg
```

**Option 3: Using pypg.py (works with .pg files directly)**
```powershell
python pypg.py tutorial\sample-problems\Algebra\Logarithms.pg
```

## Normal vs Standalone Mode

### Normal Mode (Default)
```powershell
python -m pg_translator.cli problem.pg
```
- Imports placed AFTER DOCUMENT() (for sandbox execution)
- No MathObjects auto-import
- No execution boilerplate
- Designed for PGTranslator/sandbox execution

### Standalone Mode (--standalone)
```powershell
python -m pg_translator.cli problem.pg --standalone
```
- Imports placed BEFORE DOCUMENT() (syntactically valid Python)
- MathObjects auto-imported
- Execution boilerplate added
- Can be run directly with proper PYTHONPATH

## Import Format

Both modes now use clean, short imports (1:1 Perl parity):

### Before (old format)
```python
from pg_macros.answers.pg_answer_macros import num_cmp, str_cmp, fun_cmp
from pg_pgml import PGML
```

### After (new format)
```python
from PGML import *
from PGstandard import *
from PGcourse import *
```

## Comparison with Perl

Just like in Perl WeBWorK:
- `.pg` files in Perl are **not standalone** - they need WeBWorK::PG::Translator
- `.pyg` files in Python are **not standalone** by default - they need PGTranslator
- Both require a runtime environment to execute properly

The `--standalone` flag is a convenience feature that makes .pyg files **more** standalone than .pg files in Perl!

## Examples

### Generate and Run
```powershell
# Generate standalone file
python -m pg_translator.cli tutorial/sample-problems/Algebra/Logarithms.pg --standalone

# Run it
.\run-pyg.bat tutorial\sample-problems\Algebra\Logarithms.pyg
```

### Quick Test Workflow
```powershell
# Generate + run in one go
python -m pg_translator.cli tutorial/sample-problems/Algebra/Logarithms.pg -o test.pyg --standalone --overwrite && .\run-pyg.bat test.pyg
```
