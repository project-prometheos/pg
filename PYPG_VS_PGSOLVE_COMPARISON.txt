                          pg_solve.py EXECUTION
--------------------------------------------------------------------------------
STEP 1: Preprocess with Pygments+Lark
  Method: Tokenize, parse Perl syntax, convert to Python
  
  Input:  $a = non_zero_random(-9, 9);
  Output: a = non_zero_random(-9, 9)
  
  Input:  do { $b = random(2, 9) } until $b != $a;

              b = random(2, 9)
              if b != a:
                  break
  
  Input:  $answer2 = Compute("($a x^($b) + $b)/x")->reduce();
  Output: answer2 = Compute(f"({a} x^({b}) + {b})/x").reduce()
  
  Result: ✅ Valid Python code generated

STEP 2: Execute in Sandbox
  Method: RestrictedPython with macro stubs
  
  a = non_zero_random(-9, 9)     → a = -1
  while True:
      b = random(2, 9)            → b = 9 (first iteration)
      if b != a:                  → 9 != -1 → True
          break                   → Exit loop
  answer2 = Compute(f"({-1} x^({9}) + {9})/x").reduce()
                                  → "(-1*x^9 + 9)/x" → "(9 - x**9)/x"
  
  Result: ✅ Variables properly evaluated

STEP 3: Render PGML with Variables
  Method: PGMLRenderer with variable substitution
  
  Input:  [``[$answer2]``]
  Lookup: answer2 = "(9 - x**9)/x"
  Output: (9 - x**9)/x
  
  Result: ✅ Correct formula

CORRECTNESS: ✅ CORRECT - variables fully expanded

================================================================================

                      WHY SYNTAX ERRORS DIFFER
================================================================================

pypg.py:
  - Assumes code is already Python
  - Doesn't translate Perl syntax
  - Silently ignores unsupported constructs
  - Result: ❌ NO ERRORS but WRONG OUTPUT
  
pg_solve.py:
  - Actively translates Perl to Python
  - Can fail on complex Perl constructs
  - Raises SyntaxError when translation incomplete
  - Result: ✅ ERRORS but attempts to be CORRECT

Example causing syntax error in pg_solve.py:

  Perl: $text = "Hello " . $name . "!";
        └────────────────────────────┘
               Concatenation with .
  
  pg_solve.py: Tries to convert . to +
               May produce: text = "Hello " . name . "!"
               Result: SyntaxError: invalid syntax
  
  pypg.py: Doesn't execute this line
           Result: No error, but $text undefined
